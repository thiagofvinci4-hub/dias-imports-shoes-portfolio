# App Dias Imports Shoes

Aplicativo híbrido Android/iOS desenvolvido com React Native, Expo e TypeScript. Ele se conecta a uma API Flask compatível; configure a URL da API no `.env` antes de executar.

## Desenvolvimento

```bash
npm install
npx expo start
```

Escaneie o QR Code com o Expo Go. Para compilar versões de distribuição, configure a conta Expo/EAS e o identificador de projeto conforme a documentação do Expo.
